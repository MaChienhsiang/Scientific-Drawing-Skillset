# BSG 蒸馏概览

## 主旨

Building Science Graphics 将科学内容转译为可导航、可核查的视觉语言：先理解主张、受众和关系，再用构图、感知分组、颜色、字体、迭代和出版前检查澄清复杂性。

## 骨架

1. 科学传播与图形类型：图形承担描述、流程、比较、解释和总结。
2. 感知与视觉语法：分组、图地、符号、视觉变量和箭头组织关系。
3. 构图与强调：层级、网格、对齐、负空间、信息流和海报布局。
4. 颜色、字体与风格：语义颜色、可读排版、媒介和受众适配。
5. 故事、复杂性与不确定性：用视觉路径表达机制、证据、未知和限制。
6. 工作流与协作：缩略图、概念草图、反馈、终稿、preflight 和改版。

## 关键任务

| task | 交付 | 位置 |
|---|---|---|
| 将科学主张变成阅读路径 | 主张句、故事板、动线 | ch.3, 11, 15–16 |
| 组织复杂关系 | 网格、对齐、留白、层级、箭头语法 | ch.6–7 |
| 建立可信视觉编码 | 颜色、字体、符号、可访问性 | ch.6, 8–10 |
| 面向出版交付 | 尺寸、分辨率、格式、来源、alt text | ch.15–16 |

## 批判与范围

BSG 自承原则主要来自欧美现代设计传统，且含科学新闻/科普案例；本技能泛化其可验证结构，不把案例画风或书籍建议冒充某期刊硬性规范。Nature Reviews 等期刊的具体要求需按目标刊最新指南核对。
