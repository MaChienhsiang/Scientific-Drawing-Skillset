# Scientific Figure

## R — 来源与核心

BSG 把科学图形视为一种视觉语言：先明确内容和受众，再设计读者如何进入、分组、推进和理解复杂关系。其可迁移核心是“澄清而非抹平复杂性”，用感知分组、层级、网格、对齐、负空间、颜色、字体和箭头把科学论证组织成可核查的视觉路径（章节 4–9、15–16、18）。本技能抽取的是可执行设计方法；书中新闻图、科普插画和案例的具体画风不构成科研出版硬规范。

## I — 视觉故事和版面规则

1. **先写主张**：用一句话说明图要让读者理解的结论、机制、比较或趋势；列出对象、关系、方向、条件、单位、证据和未知项。每条线、颜色和标记都必须服务其中一项。
2. **设计阅读路径**：在动手画前写“入口 → 背景/条件 → 机制或数据 → 转折/比较 → 结果 → 限制/不确定性”。让空间方向、面板顺序、层级和箭头共同表达逻辑；避免对象清单式堆叠。
3. **选择图型服从关系**：流程/闭环表达时间和输入输出；架构图表达层级与接口；地图/场景图表达空间尺度；热力图表达二维位置与数值；数据图表达分布、趋势和不确定性；多面板每块有唯一职责并用编号或连接建立总览—细节关系。
4. **用澄清代替过度简化**：删除噪声、重复和无关装饰，但保留会改变解释的变量、边界、异常和不确定性。不能因为“好看”隐去关键对照或误差。
5. **建立网格与对齐**：先定画布、边距、列/行、基线和面板间距。标题、图例、坐标轴、标签、面板边界和连接线应吸附同一网格；对齐优先于填满空间。用一致间距表达分组，用留白隔开层级，允许空白“呼吸”。
6. **控制比例和层级**：比例应由科学关系、尺度或比较任务决定；不要用面积、透视或 3D 夸大数量。一级信息获得最大对比度/字号/线宽，背景和次要结构降明度；缩到最终栏宽仍能辨认主张、主路径、坐标和图例。
7. **语义配色**：颜色编码类别、状态、方向或数值，不作装饰。连续变量使用感知均匀、方向明确的序列；发散变量以中点为语义中心；分类色数量有限且可区分。颜色之外再用位置、线型、形状或文字冗余编码；检查色盲、灰度和印刷。
8. **箭头与符号有固定语法**：实线/虚线、单/双向、端点、线宽和曲率各自只表达一种关系（流向、因果、依赖、反馈或不确定性）。箭头不要同时承担“流程线”和“指注线”；必要时用引导线或标注。学科符号先给语境或图例，避免未解释的视觉术语。
9. **字体与排版**：采用少量可嵌入、跨平台、可读字体；标题、面板标题、正文、轴标签、图例、注释建立明确等级，统一字重、大小、行距、对齐和上下标。文字短而具体，避免全大写、拥挤旋转和模型生成的小字；最终标签在矢量编辑器中排版和校对。
10. **交付比例和技术质量**：按目标期刊/会议的最新指南确定单栏/双栏尺寸、长宽比、最小字号、线宽、色彩模式、分辨率、字体嵌入和文件格式。优先 SVG/PDF/可编辑对象；栅格只用于真实影像或纹理，并按最终尺寸检查分辨率。

## A — 执行流程

### 1. 事实锁与故事板
输出主张句、对象/关系/方向/条件/证据表、未知项清单；画低保真缩略图，标出入口、动线、面板职责、网格、留白和比例。

### 2. 视觉规格
写出布局、尺寸、图层、颜色映射、线型/箭头语法、字体层级、图例和标签位置。对数据图注明数据来源、统计定义、坐标单位、误差/置信区间和缺失值处理。

### 3. 分轮制作与审查
结构轮只审主张、路径、比例和分组；语法轮审颜色、线型、字体、对齐和可访问性；事实轮逐项核对数据、方向、尺度、单位、因果、不确定性、图例和引用。请领域专家审事实，请目标读者审阅读路径。

### 4. 出版前检查
在目标尺寸和缩略图下检查可读性；检查字体、颜色模式、分辨率、透明度、嵌入字体、裁切、图注、来源、版权和 alt text。保存可编辑源文件及版本记录。

## 可选联合接口 — LayoutSpec / FigureSpec v1

可单独使用：若没有上游规格，先询问或提取 `claim`、`audience`、`figure_type`、`reading_path` 和 `unknowns`，不能凭“顶刊风格”猜测版式。

接收 `scientific-plot` 的 `figure_spec` 后，保留 `task`、`claim`、`data_facts`、`encodings` 和 `relations`，补充：

```yaml
layout:
  canvas_ratio: "比例与最终栏宽"
  panels: ["编号、唯一职责、占比、互相引用"]
  reading_path: ["入口", "主路径", "结果", "限制"]
  grid: "边距、列/行、基线、间距、对齐轴"
  whitespace: "分组与呼吸的规则"
  typography: "字体、层级、字号、行距、标签策略"
  legend_and_caption: "位置与内容"
  publication: "目标期刊/会议及待核查技术参数"
```

联合使用时，将 `FigureSpec + layout` 交给 `scientific-illustrator`，它只能把已确认的对象、关系和版式翻译成 Prompt 或可编辑对象计划，不得新增科学事实；完成插图后，将渲染结果和 `unknowns` 交回本技能做出版前检查。单独使用时直接完成从主张、故事板到版式和出版检查的全流程。若任务是纯数据图，直接把 LayoutSpec 与 DataEncodingSpec 合并后交给绘图工具。

## B — 明确边界

科研图不是商业广告、自媒体封面或产品宣传。禁止 Emoji、过度装饰的卡通 Icon、品牌标志、营销文案、霓虹/玻璃拟态、花哨渐变、电影光效、金属高光、无语义阴影、3D 炫技、贴纸、表情包和纯审美纹理；禁止用这些元素制造“高级”“顶刊”错觉。若用户要传播版，可另做副本，但不得把商业视觉规则混入论文图。

禁止 AI 臆造实验数据、显著性、坐标、样本、结构、机制、比例或引用。缺少真实数据/事实时停在规格或占位草图。期刊名称只能作为参考对象；“符合 Nature Reviews”等出版判断必须核对目标期刊当期作者指南和图像政策，BSG 本身不等于期刊标准。

不替代统计分析、领域事实审核、伦理审查、软件操作指南或正式投稿检查。设计原则源自 BSG 的西方现代设计传统，适用性需结合学科、读者、文化语境和无障碍要求验证。

## E — 完成标准

- 一句话主张和阅读路径清晰；每个视觉编码有语义和证据。
- 网格、留白、对齐和比例支持分组与层级；没有孤立面板或无主线装饰。
- 颜色、线型、形状和文字提供冗余编码，色盲/灰度/印刷仍可解释。
- 最终尺寸下字体、图例、坐标、误差和数据来源可读；关键对象可编辑。
- 事实、数据、引用、版权和期刊技术要求均已核对，未核对项显式标记。
