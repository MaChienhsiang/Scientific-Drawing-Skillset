## 1. 结构

### 类型

跨学科科研绘图案例集，夹杂提示词工程、生成工具介绍、期刊风格观察、矢量化和工作流建议。

### 一句话主旨

高质量 AI 科研图的核心不是追逐工具或模仿某个期刊名称，而是把科学主张、阅读顺序、信息架构和视觉语法写成可检查的规格，再通过迭代和可编辑化交付。

### 骨架

1. 用科学主张和视觉剧本取代“画得好看”的模糊要求。
2. 用面板、空间、动线和层级组织复杂科学关系。
3. 用语义配色、箭头、字体、留白和负面约束控制生成模型。
4. 用结构轮、风格轮、事实轮迭代，建立反馈和 prompt 资产。
5. 用专家核对、缩略图检查和矢量化把初稿变成可用图件。

关系：递进，前两层定义要表达什么，中间两层定义怎么生成，最后一层决定是否能交付。

### 核心问题

如何让不懂用户专业领域的生成模型，稳定地产出跨主题、可读、科学准确且可继续编辑的科研图？

## 2. 解释

### 关键术语

| 术语 | 在整理稿中的用法 |
|---|---|
| 科学叙事/视觉剧本 | 用阅读顺序表达主张、机制、转折、结果和边界，而不是罗列对象 |
| 视觉规格书 | 将审美翻译成比例、色值、线型、字体、面板、留白和禁止项 |
| 语义配色 | 颜色在全图中稳定代表同一类状态、对象或关系 |
| 信息层级 | 用大小、位置、饱和度、线宽和留白区分主次 |
| 负面约束 | 明确禁止会把图带偏的风格、元素、文字和结构 |
| 缩略图可读性 | 图缩到目标尺寸后仍能辨认主张、主线和核心对比 |
| 可编辑交付 | 文字、路径、面板、图例和关键对象可单独修改 |

### 核心命题

1. 图的上限受设计意图的形式化程度限制，而不是只由模型能力决定。
2. 结构先于风格；没有主张和动线，增加细节只会增加噪声。
3. 期刊风格应拆成观察到的视觉属性，不能靠名称保证结果。
4. 颜色和箭头必须表达语义，不能只负责装饰。
5. 真实数据、医学结构、化学式和工程连接不能由模型自由补全。
6. 生成图是可迭代的草稿；反馈、版本和矢量化是生产流程的一部分。

### 论证链

案例覆盖计算机、生命科学、能源、材料、地学、建筑、通信、器件和医学。跨主题重复出现“主张—布局—语义编码—负面约束—迭代—编辑”的结构，因此适合抽取为泛化 skill；工具名、具体色板、分辨率和期刊名称只保留为可选案例，不作为硬规则。

## 3. 批判

### 时代和来源局限

- 资料依赖社交媒体帖子，部分描述是个人经验和营销语气，不等于经过同行评审的设计规范。
- 工具、模型版本和期刊风格会变化，不能把某一时期的模型能力当作永久能力。
- 页首的抓取时间与正文条目日期不一致，数量“89 篇”与正文可见编号也不一致。

### 未被证明的假设

- 更长的 prompt 不一定更稳定；约束的相关性和优先级更重要。
- “接近顶刊”不是可自动验证的指标，必须拆成可检查的结构、事实、可读性和编辑性。
- 自动矢量化不一定产生干净图层，复杂渐变和文字仍需人工重建。

### 最强反对意见

许多工作流把视觉设计问题过度归因于 prompt，忽略了数据质量、领域知识、后期排版和真实期刊规范。回应方式不是否认工具价值，而是把专家核查、真实数据和可编辑交付放进验收标准。

## 4. 应用潜力

### 可 skill 化

- 跨学科科研图的主张和事实锁定。
- 视觉剧本、版式、面板和动线设计。
- 语义配色、箭头、标注、留白和负面约束规格化。
- AI prompt 的结构化编写与分阶段迭代。
- 科学性、缩略图、可访问性、打印和可编辑性验收。

### 只作为参考

- 单个工具、网站、模型版本和商业链接。
- 某个期刊的具体色板或“完全复刻”说法。
- 帖子中的个人宣传语、粉丝互动和未核验的质量比较。
