# 科研绘图技能术语

| 术语 | 工作定义 |
|---|---|
| 科学主张 | 图希望读者接受或理解的一句话结论、机制或关系 |
| 视觉剧本 | 为读者规定起点、动线、转折、结果和边界的文字计划 |
| storyboard | 在生成前描述版式、面板、对象、连接和比例的草图规格 |
| 信息层级 | 通过位置、大小、对比、饱和度和留白表达主次 |
| 语义配色 | 颜色与对象、状态、流程或证据类别之间的稳定映射 |
| 箭头语法 | 用方向、线型、粗细、端点和曲率区分因果、流向、依赖、反馈和警告 |
| 负面约束 | 显式禁止会造成事实、构图、风格或可读性问题的输出 |
| 机制图 | 解释对象如何相互作用、转化或产生结果的图 |
| 流程图 | 解释有序步骤、输入输出或闭环控制的图 |
| 多面板图 | 将总览、局部、对比或证据拆成互相关联的面板 |
| 放大框 | 从总览区域引出并放大局部机制的视觉连接 |
| 缩略图可读性 | 在目标栏宽或小尺寸下仍能读出核心结构 |
| 2.5D/等轴视角 | 用有限透视和浅阴影表达层次，不等同于照片级 3D |
| 科学事实锁 | 对象、关系、方向、单位、证据和禁止臆造项的清单 |
| 可编辑交付 | 关键文字、路径、面板、图例和对象可以独立修改 |
| prompt 资产 | 经验证的 prompt、参考图、反馈和版本记录的集合 |
