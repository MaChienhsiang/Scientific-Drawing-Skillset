# 已验证能力单元

本次采用一个来源路由入口 `scientific-illustrator`，内部保留五个原子能力。它们共享同一触发入口，避免多个“科研绘图” skill 互相抢调用。

## C1 — 科学主张与事实锁定

- **V1 来源充分性**：通过。整理稿第 1、2、5、6、7、8、55、89 条反复要求先明确科学故事、结构和事实细节。
- **V2 可执行性**：通过。给定任意论文段落，可输出主张、对象、关系、方向、条件和禁止臆造项。
- **V3 任务增益**：通过。减少模型自行补全机制、数字和方向造成的科学错误。
- **去向**：router 内部能力。

## C2 — 视觉剧本与版式

- **V1 来源充分性**：通过。第 2、3、6、7、8、54、55 条给出从主张到面板、动线和空间分区的完整机制。
- **V2 可执行性**：通过。可为流程、闭环、对比、多面板和空间图生成 storyboard。
- **V3 任务增益**：通过。减少对象堆砌和面板孤岛，稳定读者阅读路径。
- **去向**：router 内部能力。

## C3 — 视觉语法与 prompt 规格

- **V1 来源充分性**：通过。第 3、4、6、7、19、41、48–50、86、88 条明确要求具体比例、色值、线型、字体、负面约束和文本策略。
- **V2 可执行性**：通过。可生成正向 prompt、负面 prompt 和模型无关的规格表。
- **V3 任务增益**：通过。把“高级/专业”变成可检查的设计参数。
- **去向**：router 内部能力。

## C4 — 迭代质检

- **V1 来源充分性**：通过。第 1、4、5、6、40、41、60、84、89 条覆盖一致性、缩略图、科学准确性和多轮反馈。
- **V2 可执行性**：通过。可按结构轮、语法轮、事实轮逐项输出修改意见。
- **V3 任务增益**：通过。使第一张生成图不再被误当作终稿。
- **去向**：router 内部能力。

## C5 — 可编辑交付

- **V1 来源充分性**：通过。第 4、83、85 条说明图片转图表、版本编辑和栅格转矢量的流程与限制。
- **V2 可执行性**：通过。可输出 SVG/Visio/Illustrator 对象分层和人工抽查清单。
- **V3 任务增益**：通过。保留论文生产流程中的改色、改字、改线和复用能力。
- **去向**：router 内部能力。

## 未晋级为独立入口的理由

五个单元都通过知识验证，但它们共享“把科学内容变成可验证科研图”的单一意图、输入和交付链，拆成五个可发现入口会增加触发竞争。按 cangjie-skill 的晋级门，统一保留在一个来源路由 skill 中。
