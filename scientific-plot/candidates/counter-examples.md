# 反例候选

1. **彩色“意大利面”线图**（ch.1）：软件默认把大量线全部突出，造成视觉噪声；应降低背景信息或分层。
2. **只呈现数字、不表达比例的国防图**（ch.2）：信息很多但读者被迫心算；不满足比较任务。
3. **过度装饰与功能冲突**（ch.3–4）：新闻图中的视觉烟火或“boom”效果可能适合大众传播，却不应自动移植到同行评审图。
4. **过多背景框**（ch.6）：盒子把各部分切碎并增加墨水；优先使用接近、对齐和留白分组。
5. **把相关性当因果或用面积夸大差异**（ch.1–2、6）：编码超出数据证据，误导读者。
6. **用户硬约束**：科研规则中禁止 Emoji、过度装饰卡通 Icon、花哨渐变、品牌和营销元素。
