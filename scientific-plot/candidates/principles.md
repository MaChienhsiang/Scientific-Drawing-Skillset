# 原则候选（TFA）

- ch.1–2：先定义读者任务（呈现、比较、组织、关联、定位或解释），再选图型；形式由功能约束。
- ch.1：图形不仅被看，也被读和核查；清晰、准确和可用优先于表面美感。
- ch.2：相同数据可能有多个正确编码，选择取决于读者问题，而不是软件默认或审美。
- ch.3–4：叙事、受众、信息密度、抽象程度和熟悉度共同决定版式；复杂性应被组织而非简单抹除。
- ch.5–7：利用注意、差异、分组、预注意特征和有限工作记忆；控制颜色和符号数量。
- ch.6：精确比较优先位置、共同基线和长度；面积、体积、颜色饱和度更适合概览或模式，不应承担精确读数。
- ch.6：相似元素保持相似编码，背景上下文可降明度但不应遮蔽主结论。
- ch.6：避免彩虹色造成伪边界；颜色需服务变量性质并考虑可访问性。
- ch.8：结构、颜色和字体先规划，再制作和检查；图例、轴、标题、注释需层级一致。
- ch.6–8：使用网格、共同轴线、接近和留白组织信息，避免用过多盒子制造拥挤。
- ch.9：交互图遵循总览→缩放/筛选→细节；交互要有可见反馈、约束和一致性。
- 用户边界：学术图禁止 Emoji、卡通 Icon、商业营销元素、花哨渐变和无语义特效。
