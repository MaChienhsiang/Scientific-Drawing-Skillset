# TFA 蒸馏概览

## 主旨

Alberto Cairo 将信息图和可视化定义为帮助读者完成认知任务的“功能性艺术”：形式由任务、数据关系、受众和媒介共同约束，审美应来自清晰、准确和有效的功能。

## 骨架

1. 可视化的目的：从信息到理解与判断。
2. 形式与功能：图型选择应服务呈现、比较、组织和关联。
3. 美感与叙事：功能性、密度、抽象程度、熟悉度和装饰之间要平衡。
4. 复杂性与认知：图不是简单化信息，而是让复杂信息可读。
5. 视觉认知：注意、差异、分组、预注意特征和工作记忆限制影响设计。
6. 实践与交互：结构、颜色、字体、反馈、约束、一致性和总览—细节路径。

## 范围与批判

TFA 主要来自信息设计、数据可视化和新闻图形实践，含互动媒体与大众传播案例。它能提供功能导向、认知和图型选择原则，但不能代替领域统计规范或任何期刊作者指南。书中“漂亮”“有趣”和互动效果必须服从科研图的可复核性与克制要求。
