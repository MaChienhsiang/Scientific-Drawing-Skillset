# 已验证能力

统一入口 `scientific-plot`，包含五项能力：

1. **任务—主张—图型匹配**：根据读者任务选择位置、长度、趋势、关系、空间或结构编码。
2. **视觉故事与版面**：设计入口、动线、信息层级、网格、对齐和留白。
3. **认知友好编码**：利用差异、分组、共同基线、颜色和形状，并控制工作记忆负担。
4. **跨图型与数据严谨性**：覆盖机制、流程、架构、热力图、地图和统计图，保留尺度、单位、误差和不确定性。
5. **学术交付审查**：检查事实、可读性、可访问性、版权、文件和目标期刊要求。

五项通过来源充分性、可执行性和任务增益检查；出处与限制见 `references.md` 和 `needs-review.md`。
