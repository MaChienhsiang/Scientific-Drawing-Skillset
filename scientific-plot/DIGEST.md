# Scientific Plot 精华

科研图是帮助读者完成认知任务的工具。先问读者要比较什么、发现什么、追踪什么或理解什么，再写主张、证据、关系、单位和不确定性。图型选择应服从任务：位置和共同基线适合精确比较，折线适合趋势，散点适合关联，地图适合空间关系，热力图适合模式概览，流程和架构图适合状态、层级与接口。

视觉故事需要入口、主路径、转折、结果和限制。总览先交代主题，再展开细节；多面板按逻辑编号并共享编码。网格、对齐、接近、相似、连续和留白帮助读者分组；标题、图例、坐标、标签和图注应有清晰层级。颜色只承担稳定语义，重要信息用颜色之外的形状、线型、位置或文字再编码。

复杂性应被组织和澄清，而不是被装饰或删掉。不要用面积、体积、透视、彩虹色或高光制造虚假差异，不要把相关性暗示成因果。论文图禁止 Emoji、卡通 Icon、营销元素、花哨渐变和无语义特效。最终交付要在栏宽、缩略图、灰度和印刷条件下核对，并遵循目标期刊最新要求。
