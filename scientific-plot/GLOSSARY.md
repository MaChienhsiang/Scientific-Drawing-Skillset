# 术语

| 术语 | 工作定义 |
|---|---|
| 读者任务 | 读者需要从图中完成的呈现、比较、组织、关联、定位或解释动作 |
| 科学主张 | 图希望读者理解或接受的一句话结论、关系或机制 |
| 功能约束 | 图型、编码和版面必须服从的任务、数据关系、受众和媒介 |
| 视觉故事 | 入口、动线、转折、结果和限制组成的阅读结构 |
| 预注意特征 | 无需逐项搜索即可快速感知的颜色、位置、长度、方向、大小或边界差异 |
| 数据墨水 | 直接编码数据或帮助读者理解数据的视觉成分；不等于盲目删减所有非数据元素 |
| 冗余编码 | 用颜色之外的形状、位置、线型或文字重复表达关键信息 |
| 总览—缩放—细节 | 先给全局，再允许探索，最后提供按需细节的组织结构 |
